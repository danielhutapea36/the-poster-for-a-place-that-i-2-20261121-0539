A travel poster for a place that does not exist, for the make.fun
`the-poster-for-a-place-that-i-2-20261121-0539` bounty.

## The place

**Velmara** is a valley of floating islands at golden hour, where the
waterfalls fall upward — ribbons of water rising from the islands into a
violet and amber sky. Lantern-lit houses perch on the islands, and
sailboats drift on the calm turquoise lake below. There is nowhere like
it, because there is no Velmara on any map: the one landmark you cannot
forget is the water going the wrong way, up into the sky.

The poster is built to the judge's brief: an invented place with a
distinct identity (the upward waterfalls), its name set large and legible
into the picture, one clear promise of what a stay there would feel like
— a slow golden evening on the lake, looking up — and a purposeful
palette of deep violet, teal and amber leading the eye from the name to
the islands and the horizon.

## How it works

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` byte-for-byte into the output directory
(`$MAKEFUN_OUTPUT_DIR`, default `/output`). It first checks the PNG
magic bytes of the source, copies the file, then re-checks the magic
bytes of the copy and prints its size and SHA-256. No network, no
randomness, no timestamps — two runs write identical bytes.

Run it locally with:

```
MAKEFUN_OUTPUT_DIR=/tmp/velmara-out python3 main.py
```
